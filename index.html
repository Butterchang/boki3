03

第 2 問 解題套路

第 2 問常不是純分錄，而是「理解帳簿之間的關係」。核心心法：勘定記入先寫分錄再搬帳戶、摘要寫相手科目。

A勘定記入（T字帳填寫）▸
  1. 把題目所有交易先全部寫成分錄，不要憑感覺直接填 T 字帳。
  2. 找到目標勘定，看它在每筆分錄出現在借方還是貸方，就寫進帳戶的同一邊。
  3. 摘要寫「相手科目」（對方科目）。例：現金回收売掛金，売掛金帳戶貸方那行摘要寫「現金」。
  4. 最後補餘額：資產帳戶餘額在借方，故貸方寫「次期繰越」平衡；下一期借方寫「前期繰越」。負債／純資產相反。
売掛金（資産）：増加→借方（相手 売上）　／　回収・返品・貸倒→貸方（相手 現金・売上）
易錯：「次期繰越」是為了平衡而寫，金額＝借貸差額。把它和真正的交易分錄混淆，或方向放反，是最常見的失分。
B補助簿（売掛金元帳・商品有高帳 等）▸

先確認該補助簿按什麼維度記錄：売掛金元帳按得意先（客戶）、買掛金元帳按仕入先（供應商）。總帳的売掛金餘額＝所有客戶売掛金餘額合計。

商品有高帳管理數量・單價・金額，兩種方法：

  1. 先入先出法：先買的先賣出，払出成本按較早批次計算，期末留下較新批次。
  2. 移動平均法：每次購入後重算平均單價＝(残高金額+仕入金額)÷(残高数量+仕入数量)，之後的払出與残高都用這個單價，直到下次購入。
易錯：商品有高帳記的是「商品的進出與成本」，不記銷售價格（売価）。三分法日常分錄只認売上，商品有高帳只管成本流動。
C補助簿の選択（空欄補充常見型）▸

給一筆交易，問「會記入哪些補助簿」。做法：把交易拆解成幾個動作，每個動作對應一本帳。

  1. 有進貨 → 仕入帳；有銷售 → 売上帳。
  2. 商品數量有變 → 商品有高帳（含含運費的進貨）。
  3. 掛 → 買掛金元帳／売掛金元帳；現金 → 現金出納帳；他人振出小切手＝現金 → 現金出納帳。
  4. 手形 → 受取／支払手形記入帳；當座小切手 → 当座預金出納帳。
04

第 3 問 精算表の稿紙法

第 3 問看起來複雜，是因為資訊量大。穩定拿分＝把它拆成 7 條獨立的整理仕訳，逐條寫、逐條填，不要同時想整張表。

①解題六步▸
  1. 先看會計期間與決算日（決定月割）。
  2. 把整理事項逐條做成分錄（在題目旁打草稿：①現金過不足 ②売上原価 ③貸倒 ④減価償却 ⑤消費税 ⑥経過勘定 ⑦法人税等）。
  3. 涉及時間分攤時畫月份線。
  4. 把分錄填入修正記入欄（借→修正借、貸→修正貸）。
  5. 資産／負債／純資産 → 貸借対照表欄；収益／費用 → 損益計算書欄。同一科目若試算表餘額＋修正額，合併後再進 P/L 或 B/S。
  6. 算出当期純利益，使兩張表平衡。
当期純利益的方向：P/L 費用在借、收益在貸。收益＞費用時，利益填 P/L 借方（讓 P/L 左右平衡）；利益增加純資產，故 B/S 貸方。虧損相反。
②三項最後檢查▸
  1. 修正記入欄借貸合計相等。
  2. P/L 與 B/S 的利益金額一致、方向相反。
  3. 当期純利益已反映到繰越利益剰余金（財務諸表的連結：PL の当期純利益 → BS の純資産）。

還有：前払・未収是資產；前受・未払是負債。減価償却累計額、貸倒引当金在 B/S 是資產的控除項（△）。

借方｜貸方　左右必須相等。
第2問搬帳戶、第3問拆 7 條 ── 把大題拆小，平衡自然浮現。
